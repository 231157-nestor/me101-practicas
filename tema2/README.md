\# Contenido del Proyecto - Tema 2



Esta carpeta contiene los ejercicios y scripts desarrollados para la práctica de entornos reproducibles:



\* \*\*tarea1.ipynb\*\*: Cuaderno de Jupyter que contiene los ejercicios en Python. Se ejecuta dentro de un entorno Conda dedicado con Jupyter Notebook o JupyterLab instalado.

\* \*\*tarea2.R\*\*: Script en R con las rutinas de análisis y manipulación de datos. Se ejecuta en RStudio y requiere la instalación y carga del paquete `tidyverse`.

\* \*\*README.md\*\*: Documentación de la estructura del proyecto y requisitos de ejecución de cada script.
